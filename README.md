# SOUQ Landing Page
**Curated Commerce & Premium Marketplace Teaser Page**  
**Domain:** [https://souqonline.in](https://souqonline.in)  

SOUQ is an upcoming premium marketplace designed to connect discerning consumers with verified, highly trusted local businesses and artisanal merchants. This repository contains the complete landing page, design system, technical architecture specifications, and React 19 codebase.

---

## 🌟 Tech Stack
* **Framework:** React 19 (Vite 6)
* **Language:** TypeScript 5.x (Strict Mode)
* **Styling:** Tailwind CSS v4
* **Animations:** Framer Motion 12
* **Icons:** Lucide React
* **Backend Integration:** Supabase (Waitlist DB & Row Level Security)
* **Typography:** Space Grotesk & JetBrains Mono

---

## 📁 Repository Structure
* `PRODUCT_SPECIFICATION.md` — Complete Product Specification & 100% Verbatim Microcopy Engine.
* `DESIGN_SYSTEM.md` — Visual System, Monochrome Palette, 8px Spatial Grid, Motion Curves, and JSON Design Tokens.
* `TECHNICAL_ARCHITECTURE.md` — Scalable Next.js/React Engineering Blueprint, Nginx Proxy Script, & Security Configuration.
* `PRODUCTION_READINESS_REPORT.md` — 15-Phase Production Readiness Audit Report & Deployment Approval (Score: 99.2/100).
* `src/` — React 19 source code, layout containers, section components, UI primitives, and motion modules.

## 🚀 Getting Started

### Installation
```bash
pnpm install
```

### Local Development
```bash
pnpm dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
pnpm build
```
